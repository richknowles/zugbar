# ⚡ Zugbar

**Zugbar** is a stackable, privacy-first network monitor for Waybar. 
Visualize your data flow like electricity on your CachyOS/Hyprland desktop.

Built with ❤️ and a little bit of Swiss destiny. 🇨🇭🐱

## ✨ Features
- **Stackable:** Fits perfectly into your existing Waybar layout.
- **Real-time:** Monitors upload/download speeds instantly.
- **Privacy First:** No telemetry, no cloud, just local data.
- **Electric Vibe:** Designed to look like flowing current.
